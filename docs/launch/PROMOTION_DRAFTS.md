## English

### Discord / GitHub Discussion

AgentDiag v0.1.1 is a read-only CLI for diagnosing Hermes Agent and OMP environments. It inventories skills, plugins, and MCP configuration without running agent binaries or third-party code. This update improves Hermes discovery accuracy, adds `POSSIBLE` confidence labels, and avoids false warnings for valid `SKILL.md` YAML. Feedback on other agent adapters is welcome: https://github.com/TheJarv1s/agentdiag/releases/tag/v0.1.1

### Reddit

I built AgentDiag to answer a frustrating question in agent setups: “the file exists, but will the agent actually discover it?” It scans Hermes and OMP configuration in read-only mode, checks skill/plugin/MCP structure, and exports sanitized reports. v0.1.1 tightens Hermes discovery and makes heuristics explicit. I would value feedback from people maintaining multi-agent environments: https://github.com/TheJarv1s/agentdiag/releases/tag/v0.1.1
